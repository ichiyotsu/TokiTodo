# 新增功能

## I. 待办

卡片改为四角等圆角，标题、时长、待办集、专注次数与按钮保持在同一行，压缩卡片高度。

## II. 锁机

移除大号锁插画，只保留小锁图标；内容在深色模式下进一步压暗。

## III. 我的

降低未来倒计时、专注历史、许愿墙快捷栏高度，重新调整图标与文字比例；移除「主题颜色搭配」入口。

## IV. 备份与恢复

导出 / 导入进入独立页面，标题为「备份 | 恢复」；备份包含待办、待办集、记录、设置，以及封面、头像和计时背景图片，导入前有覆盖确认。

## V. 设置入口

「备份 | 恢复」使用独立标题，不再跳转到「其他设置」；关于信息从其他设置中移除，保持独立入口。

# 设计特性

## I. 新应用图标

使用 Material Symbols `list-alt-check`，108dp 自适应图标 + monochrome，背景使用 TokiTodo 松针绿。

## II. 更紧凑的待办卡片

四角等圆角、单行信息布局和更低高度，让列表在单手操作时更易扫读。

## III. 更安静的锁机页

去掉大插画，仅保留小锁图标；深色模式背景更暗，减少锁机时的视觉干扰。

## IV. 更轻的快捷栏

我的页快捷栏降低高度，图标与文字重新配比，减少首屏占用。
